# VayuNet Final Demo Presentation

## 5-minute flow

### 0:00–0:30 — Problem
Pollution incidents are fragmented across sensors, citizens, official monitors, weather and satellite signals.

### 0:30–1:30 — Detect
Open the Command Center and show the hotspot list and overview metrics.

Explain that the system fuses evidence and surfaces a likely incident rather than making an unsupported exact-source claim.

### 1:30–2:20 — Predict
Select a hotspot and show the AQI forecast, plume projection and population exposure.

### 2:20–3:10 — Respond
Open the authority alert panel. Explain the state machine and how a routed incident moves toward acknowledgement, action and resolution.

### 3:10–4:00 — Ask Gemini
Ask one operational question. Point out the tools used and that the answer is grounded in backend results.

### 4:00–4:40 — Learn across cities
Show the federation panel and explain the three simulated nodes and global model version.

### 4:40–5:00 — Close
Show the final impact story and summarize the complete loop:

Detect → Predict → Explain → Route → Learn.

## Presentation rule

Only describe a capability as live when the application has returned a successful result for that capability.
