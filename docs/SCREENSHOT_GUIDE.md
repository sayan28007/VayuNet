# VayuNet Screenshot Guide

Capture these views for the final submission:

1. Full Command Center overview.
2. Hotspot list with one selected hotspot.
3. Predictions panel showing forecast, plume and exposure.
4. Authority response alert with visible status.
5. Gemini grounded response with tools used.
6. Federated learning status.
7. Final demo hero + impact story.

Use the same environment and dataset for all screenshots so the evidence remains internally consistent.

Do not include:
- terminal credentials
- API keys
- `.env` files
- service-account files
- personal tokens
- debug traces with secrets
